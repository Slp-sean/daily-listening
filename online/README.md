# 巧记单词在线强化记忆

Workers 提供同一学习页面与正式评级接口，D1 保存冻结 Daily Session、SRS、幂等操作和历史记录，Cloudflare Access 限制本人登录。在线词卡保留释义、巧记、例句和发音，不上传图片。

每日最后一项评级原子冻结下一日任务，定时处理调用 DeepSeek 官方 API，校验正文后调用 Workers AI 生产音频。模型调用每日最多四次，每月保守预留预算不超过人民币十元。R2 私有音频接口设置八 GB 存储上限及月度读写限制；未配置 R2 时仍可读取原 D1 音频。

部署配置以 `wrangler.example.jsonc` 为模板，在私有工作目录填写 D1、Access 和 R2 标识。`OWNER_EMAIL`、`DEEPSEEK_KEY` 用 Wrangler Secret 配置。必须先启用 Access 邮箱白名单，程序校验 JWT 后才会读取任何私人资源。缺少验证配置时返回 503。

用户数据、完整词库、音频资产、导入 SQL 和密钥均不能进入本仓库。正式数据由本机只读导出至私有目录后导入，验收副本产生的评级不能迁入正式库。

浏览器以 IndexedDB 保存待同步操作；成功提交后才清理，重试不会重复写入历史。播放位置采用版本校验；跨端冲突须由用户选择采用云端位置。桌面接管时禁用本地强化记忆写入和旧静态发布器。静态历史页面保持原目录。

回退前先导出最新云端学习状态；本机旧档案只能供追溯，不能覆盖接管后新增的云端记录。域名切换独立于代码发布。正式 Worker 在 `FORMAL_ACTIVE=false` 时拒绝评级和播放进度写入；确认接管并停用旧强化记忆写入后才启用。
