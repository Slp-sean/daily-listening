# 巧记单词在线强化记忆

Workers 提供同一学习页面与正式评级接口，D1 保存冻结 Daily Session、SRS、幂等操作和历史记录，Cloudflare Access 限制本人登录。在线词卡保留释义、巧记、例句和发音，不上传图片。

全篇展示默认逐张经典词卡，可左右滑动或使用前后按钮；今日总览保留为可选视图。单词与例句通过本人认证的云端英文音频接口播放，首次生成后存入私有 R2，后续复用。发音文本只能取自正式词卡，不接受任意输入；情景与发音共用每日 9000 神经元的保守预留上限，发音新生成每日最多 200 次。

首次发音仍采用按需生成；同一段已经加载的音频再次点击会直接重播，避免主动重新加载。部署可使用受 Access 保护的自定义预览子域名，正式接管前须在手机不使用代理的情况下验收页面、登录和音频访问。

逐词自测在词头下方固定显示“模糊、认识、秒认”，揭晓答案后允许提交。左右滑动及前后按钮只切换词条，不产生评级；已提交、待同步、历史或未开放任务显示具体原因并停用评级，仍可回看完整词卡。

每日最后一项评级原子冻结下一日任务，定时处理调用 DeepSeek 官方 API，校验正文后调用 Workers AI 生产音频。每分钟的云端定时触发独立完成模型和音频工作；网页后台只复用已验证内容，不承担长时间模型任务。DeepSeek开启思考模式进行词法自查，输入最多10000 UTF-8字节、总输出最多7000 tokens（含推理），按当前高峰单价最多0.076元，加消息包装仍由0.08元预留覆盖。模型调用每日最多四次，每月保守预留预算不超过人民币十元。R2 私有音频接口设置八 GB 存储上限及月度读写限制；未配置 R2 时仍可读取原 D1 音频。

中文情景正文先通过冻结词表、标记和词法校验，再由Cloudflare托管Qwen3.8做独立语义复核；发现生硬串词或词义错配时，保留拒绝原因并交回DeepSeek正式生成器，在原每日调用和月预算内重写；新稿再次复核，合格才生产新音频。原模型返回与复核、修订流水均保留私有D1。该步骤与语音共用每日9000神经元保护，只使用现有Workers Free额度，不开通付费套餐；额度不足会保留任务等待，不放行正文。合格复核按正文hash缓存，音频重试不重复调用模型。已知免费复核额度不足时先暂停新付费生成，避免无法完成复核却继续消耗DeepSeek调用。

经用户单独授权的临时验收额度，只能通过服务器变量 `GENERATION_EXTRA_DAY`（上海日期）和 `GENERATION_EXTRA_CALLS`（仅限明确授权的追加次数，程序最多八次）配置；日期不匹配或额度无效时自动恢复每日四次。临时额度仍受同一个月度十元预算限制，不接受浏览器传入。每次调用预留八分钱是保守上界，实际收费取决于模型返回的文字用量；内容校验失败也消耗调用额度。

情景听读沿用正式 `study_listening.py:build_group_prompt` 的学习原则：少文字、高密度、自然中文语境、非故事导向。每组按词义与自然搭配组织2—4个简短工作或生活场景，以中文为主体自然嵌入目标英文词，必要时保留正确英文短语；不生成逐句英文配中文译文，也不按词表机械拼接例句。

`content_markup` 是唯一正文，格式为 `{{word|当前语境中文短义}}`；短义最多8字。显示文本和朗读文本均由正文派生，朗读去除短义，不额外加入标题或翻译。校验覆盖冻结词集、组签名、段落、标记、中文主体及已知词性搭配规则；程序检查不能代替对自然度和语义质量的判断。缓存候选必须来自相同内容契约、签名及环境；旧英文译文候选不复用，不自动改写其语义来通过校验。

当冻结组的词及词序与既有合格听读完全一致时，云端重新验证原组签名、正文、朗读哈希和音频存在性后复用正文及音频，记录来源日期并绑定当日签名；无需重复调用模型，不把复用称为新生成。

长情景音频分成最多300字符的片段生产，成功片段私有缓存供中断恢复；全部完成后合并为一条可连续播放的WAV，再清理临时片段。每个自然日按原SRS选词规则冻结当天任务，未完成旧任务和历史记录保留；页面打开可立即准备缺失听读，定时任务在电脑关闭后继续运行。

部署配置以 `wrangler.example.jsonc` 为模板，在私有工作目录填写 D1、Access 和 R2 标识。`OWNER_EMAIL`、`DEEPSEEK_KEY` 用 Wrangler Secret 配置。必须先启用 Access 邮箱白名单，程序校验 JWT 后才会读取任何私人资源。缺少验证配置时返回 503。

用户数据、完整词库、音频资产、导入 SQL 和密钥均不能进入本仓库。正式数据由本机只读导出至私有目录后导入，验收副本产生的评级不能迁入正式库。

浏览器以 IndexedDB 保存待同步操作；成功提交后才清理，重试不会重复写入历史。播放位置采用版本校验；跨端冲突须由用户选择采用云端位置。桌面接管时禁用本地强化记忆写入和旧静态发布器。静态历史页面保持原目录。

回退前先导出最新云端学习状态；本机旧档案只能供追溯，不能覆盖接管后新增的云端记录。域名切换独立于代码发布。正式 Worker 在 `FORMAL_ACTIVE=false` 时拒绝评级和播放进度写入；确认接管并停用旧强化记忆写入后才启用。
